# 向日葵打印 (Sunflower Print)

向日葵打印（Sunflower Print）是一个专为中小学生设计的高质量学习与练习纸在线生成及打印工具。项目基于 **Vue 3 + TypeScript + Vite + Ant Design Vue** 构建，支持高度自定义题型、一键直接打印、生成并下载高清晰度 PDF。

## 技术栈简介

*   **前端框架**：Vue 3 (Composition API / `<script setup>` SFC)
*   **开发工具/构建工具**：Vite 8.x + TypeScript 6.x
*   **UI 组件库**：Ant Design Vue v4.x + `@ant-design/icons-vue`
*   **状态管理**：Pinia
*   **路由管理**：Vue Router v4.x
*   **PDF 导出/生成**：`html2pdf.js` (基于 `jspdf` 和 `html2canvas`)
*   **数据监控**：Microsoft Clarity

## 核心功能模块

本系统核心提供三大类别的练习纸生成与导出打印功能：

### 1. 数学练习题模块 (`src/views/Generator.vue`)
支持多种形式的小学数学口算与解析练习，支持高度定制。
*   **支持题型**：
    *   **基础加法**：指定范围内的随机双加数加法题。
    *   **基础减法**：指定范围内的随机减法题。
    *   **破十法练习（减法）**：自动生成 11 ~ 19 减去 2 ~ 9 的破十法数学式，使用 SVG 渲染破十树的图形解构格子（分流树）。
    *   **凑十法练习（加法）**：自动生成 6 ~ 9 加上 6 ~ 9 且需要进位的凑十法数学式，同样使用 SVG 树形图渲染辅助计算过程。
    *   **加减混合运算**：三步连加连减或混合运算。
*   **控制参数**：
    *   **数字范围**：设置最大值（例如 20 以内、50 以内、100 以内的加减法）。
    *   **排版格式**：自定义输出的列数、行数（非固定排版时），自动计算最佳排布；凑十/破十法采用固定 3 列 × 5 行的 A4 纸张排版。
    *   **答案显示**：一键切换是否在输出的练习纸中渲染红色答案，方便教师与家长批改。
*   **操作输出**：
    *   **直接打印**：使用原生浏览器打印机制，支持自适应 A4 尺寸。
    *   **下载 PDF**：客户端使用 `html2pdf.js` 输出高质量无水印矢量 PDF 练习册。

### 2. 语文练习题模块 (`src/views/ChineseGenerator.vue`)
集成了汉语基础学习所需的各种经典格规与字帖。
*   **支持格规与练习纸**：
    *   **田字格作业纸**：经典的田字格排列，适用于汉字日常书写练习。
    *   **四线方格作业纸**：拼音四线格与汉字方格上下结合，适合拼音和汉字双向对照练习。
    *   **拼音作业纸**：大格距拼音四线三格本练习纸。
    *   **作文纸**：标准的 20 × 25 作文格子纸，总计 500 字布局，带有页头信息及题目行。
    *   **康奈尔笔记纸**：经典的 A4 康奈尔笔记版式，分为线索栏、笔记栏与下方的总结栏，辅以点划线辅助线。
    *   **汉语拼音描红字帖（韵母/声母/整体认读音节）**：内置拼音字母的描红练习（包含示例字母、淡色描红描线格以及空白自主练习格）。
    *   **按笔顺描红**：用户可任意输入最多 16 个汉字，页面会自动生成对应的样本和淡色描红田字格，供学生练习汉字结构与笔顺。
*   **控制参数**：
    *   支持汉字练习文本输入框，自适应截取前 16 个字符。
    *   自动进行多页 PDF 排版。

### 3. 英语练习题模块 (`src/views/EnglishGenerator.vue`)
*   **支持格规**：
    *   **英语作业纸**：高品质四线三格英文练习纸，带有底线红色基准线提示，共有 18 行。
*   **控制参数**：
    *   标准 A4 纵向排版，可直接输出并快速复印。

## 项目本地开发与部署

如需对项目进行扩展或本地运行，请在终端中执行以下操作：

### 1. 环境依赖
确保本地计算机安装了以下运行环境：
- **Node.js**：建议使用 `v18.x` 或更高版本（项目包含 `.node-version` 约定）。
- **npm** / **yarn** / **pnpm** 等依赖管理工具。

### 2. 安装依赖
进入 `dayin-website` 目录：
```bash
cd dayin-website
```
安装所有依赖：
```bash
npm install
```

### 3. 启动开发服务
运行本地开发服务，支持热重载（HMR）：
```bash
npm run dev
```
启动后，可在浏览器中打开命令行提示的本地地址（默认通常为 `http://localhost:5173/`）。

### 4. 项目打包构建
构建打包生产环境静态文件：
```bash
npm run build
```
打包生成的可部署文件将输出至 `dayin-website/dist` 目录，可直接部署在 Nginx 或静态托管服务（如 Vercel, Netlify, GitHub Pages）中。

## 打印与 PDF 导出技术细节

项目针对 A4 打印纸张尺寸（210mm × 297mm）进行了极致的像素适配：

1.  **CSS 打印媒介配置**：
    在 `style.css` 和组件内部使用了 `@media print` 样式块，隐藏了设置面板 (`.no-print`) 和顶部导航，将核心预览版面设置为 100% 满宽，并使用 `page-break-after: always;` / `break-after: page;` 完成拼音多页字帖打印的物理分页。
2.  **`html2pdf.js` 精准导出**：
    PDF 下载功能中，配置了 `windowWidth: 794` 像素宽度（该宽度在 96dpi 的浏览器分辨率下精准对应 210mm 纸宽），并设置了 `margin: 0` 以及 `jsPDF: { format: 'a4', orientation: 'portrait' }`。这可以完美规避常见的前端导出 PDF 画面拉伸、溢出和产生多余空白页等排版问题。
