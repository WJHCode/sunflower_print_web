# 向日葵打印产品功能文档

> 文档版本：V1.1
>
> 更新日期：2026-08-25
> 产品名称：向日葵打印（Sunflower Print）

## 1. 产品概述

向日葵打印是一款面向家庭与教学场景的在线 A4 学习资料生成和打印工具。用户无需安装专业排版软件，即可按学科或用途选择模板、调整内容与样式、实时预览，并直接打印或导出为 PDF、PNG 图片。

产品目前覆盖数学、语文、拼音、英语、笔记、儿童简笔画、趣味文字贴纸和乐谱八类内容，并提供留言反馈入口。

### 1.1 产品定位

- 为小学阶段的日常学习与书写训练提供可快速生成的纸质练习材料。
- 为家长和教师降低找题、制表、排版、打印的时间成本。
- 为儿童兴趣学习、家庭计划和个人笔记提供可定制的打印模板。
- 以 A4 纸张为核心输出载体，强调清楚、纯净、易打印和可复用。

### 1.2 核心价值

- **生成快**：选择模板并调整少量参数即可得到可用材料。
- **可定制**：支持题型、题量、文字、配色、版式和辅助线等设置。
- **适合打印**：针对 A4 纵向纸张进行排版和分页。
- **使用门槛低**：浏览器中即可完成预览、打印和下载。
- **覆盖面广**：兼顾文化课练习、书写训练、计划记录与兴趣启蒙。

## 3. 解决的核心场景问题

| 场景 | 常见问题 | 解决方式 |
| --- | --- | --- |
| 家庭每日练习 | 网上资料难度不匹配、广告多、格式不统一 | 按题型、数字范围和题量现场生成练习纸 |
| 教师临时出题 | 手工出题与排版耗时，重复题难控制 | 自动随机生成题目，可一键重新生成 |

| 汉字和拼音书写 | 普通文档难制作田字格、四线格与笔顺示范 | 使用专用字帖模板，自动分页并呈现描红或笔顺 |
| 个性化英语练习 | 教材单词、短文无法快速制成描红纸 | 输入单词或段落后自动生成四线三格描红页 |
| 学习与生活计划 | 手绘计划表费时，现成模板不符合习惯 | 选择计划模板并自定义栏目、标题、语言和配色 |
| 儿童绘画活动 | 临时找线稿、描红图或涂色图不方便 | 选择主题图案、版式和线条样式后直接打印 |
| 奖励与识字卡片制作 | 手工设计文字贴纸成本高 | 输入文字即可批量生成多尺寸、多配色贴纸 |
| 音乐练习 | 五线谱、简谱或乐器谱纸规格不统一 | 自定义谱表类型、间距、谱号与和弦格 |
| 移动端使用 | 手机保存和打印网页内容操作繁琐 | 支持移动端预览、系统分享保存图片及应用安装 |

## 4. 产品功能

### 4.1 数学练习题

#### 功能点

- 支持 15 类练习：
  - 基础加法
  - 基础减法
  - 破十法减法
  - 凑十法加法
  - 加减混合运算
  - 三个数连续加法
  - 三个数连续减法
  - 表内乘法
  - 表内除法
  - 元角分单位换算
  - 纸币面值兑换
  - 质量单位换算
  - 长度单位换算
  - 时间单位换算
  - 认识钟表
- 可按题型设置数字范围。
- 纸币兑换可选择“元”“元角”或“元角分”格式。
- 支持设置练习行数，部分题型采用固定的最佳版式。
- 自动显示实际生成题数。
- 支持显示或隐藏答案。
- 支持一键重新随机生成题目。
- 凑十法、破十法使用图形化计算过程辅助理解。
- 认识钟表题型使用钟面图形展示。
- 练习纸带姓名、班级、日期和得分栏。

#### 解决的问题

- 家长不会系统出题或难以持续提供同难度的新题。
- 教师制作口算纸、单位换算题和钟表题耗时。
- 凑十法、破十法只写算式，不利于儿童理解计算过程。
- 学生自测和教师批改需要答案版与空白版。

#### 适合人群

小学低年级学生、幼小衔接儿童、家长、小学数学教师、托管教师。

### 4.2 语文练习题

#### 功能点

- 提供 12 类语文与书写模板：
  - 田字格作业纸
  - 汉字偏旁练习
  - 汉字笔画练习
  - 四线方格作业纸
  - 拼音作业纸
  - 作文纸
  - 康奈尔笔记纸
  - 韵母描红字帖
  - 声母描红字帖
  - 整体认读音节描红字帖
  - 按笔顺描红
  - 拼音笔画描红
- 偏旁和笔画支持自定义输入。
- 自定义汉字练习最多支持 200 个字，并自动分页。
- 按笔顺描红可显示笔顺拆解和总笔画数。
- 拼音笔画描红可同时显示带声调拼音、笔画步骤、描红格和空白格。
- 支持导入一、二年级字库，可按顺序或随机选字。
- 拼音类字帖内置标准声母、韵母和整体认读音节。
- 所有模板使用适合手写的格线和 A4 页面布局。

#### 解决的问题

- 家庭临时需要练字纸，却没有合适规格的作业本。
- 自定义生字难以快速制成笔顺、拼音和描红结合的字帖。
- 教师需要针对课文生字或薄弱字词制作专项练习。
- 普通办公软件制作田字格、拼音格和作文格较复杂。

#### 适合人群

幼儿园大班、幼小衔接及小学低年级学生，家长，语文教师，书法启蒙教师。

### 4.3 拼音拼读练习

#### 功能点

- 支持双音节和三音节拆分拼读。
- 双音节可练习“声母 + 韵母”，三音节可练习“声母 + 介母 + 韵母”。
- 不同拼音组成部分可分别设置颜色，强化结构辨识。
- 每组可输入最多 5 个示例词组。
- 自动生成拆分、合并箭头、完整音节、带声调拼音和对应汉字。
- 支持自定义练习标题和一键重新生成。

#### 解决的问题

- 儿童容易混淆声母、介母和韵母在音节中的位置。
- 家长和教师难以手工制作带颜色区分的拼读训练卡。
- 统一教材练习无法覆盖孩子当前易错的音节组合。

#### 适合人群

拼音启蒙儿童、小学一年级学生、家长、语文教师和语言训练人员。

### 4.4 英语练习题

#### 功能点

- 提供 5 类英语模板：
  - 英语四线三格作业纸
  - 12 个月份单词练习
  - 自定义英文单词描红
  - 自定义英文段落描红
  - 26 个英文字母大小写描红
- 自定义单词支持换行、空格或中英文逗号分隔，单次最多生成 10 个。
- 段落描红支持自定义标题、副标题和正文。
- 模板同时提供示范、浅色描红和空白书写区域。
- 月份练习带中文释义；内置常用词可显示音标提示。
- 使用适合英文手写的字体和四线三格排版。

#### 解决的问题

- 学生需要反复抄写教材词汇，但普通横线纸无法规范字母占格。
- 家长无法方便地把任意单词或短文转换成描红字帖。
- 英文字母大小写、月份等基础内容缺少集中练习材料。

#### 适合人群

英语启蒙儿童、小学生、家长、小学英语教师和课外英语机构。

### 4.5 笔记与计划模板

#### 功能点

- 提供 8 类模板：
  - 周餐计划
  - 康奈尔笔记
  - 待办清单
  - 周计划
  - 点阵笔记
  - 六边形网格
  - 学院横线纸
  - 学习计划
- 提供鼠尾草绿、北欧深蓝、温暖沙色、蜜桃粉乳和简约黑白五种主题。
- 周餐计划可设置标题、购物清单标题、中英文星期、周一或周日起始、餐次分类和分隔线。
- 康奈尔笔记可选择空白、横线、网格或点阵背景，并调整间距。
- 待办清单可选择是否显示核心任务、习惯打卡和随手记。
- 周计划可选择是否显示本周目标。
- 点阵、六边形和横线纸可调整标题、页眉、背景、颜色、间距和线条粗细。
- 学院横线纸可设置垂直边栏线的位置与颜色。
- 学习计划可自定义准备事项和奖励目标。

#### 解决的问题

- 用户需要纸质计划表，但现成模板的栏目、语言或风格不合适。
- 不同笔记方法需要不同纸张背景，手工制作成本高。
- 学习前准备、任务拆分、习惯打卡和复盘缺少统一载体。

#### 适合人群

学生、教师、家长、自学者、手账爱好者及需要纸质任务管理的人群。

### 4.6 儿童简笔画

#### 功能点

- 内置魔法童话、男孩与载具、女孩与自然、动物等分类图案。
- 支持单图填色、描红临摹对比卡、四合一卡片和六合一卡片版式。
- 支持彩色漫画和黑白线稿两种模式。
- 线条可选择实线、虚线描红或浅灰线，并可调整粗细。
- 可叠加十字线、网格或点阵辅助线。
- 可显示图案名称和拼音。
- 支持显示纸张底纹。
- 可单选、多选或按分类批量选择图案，并自动分页。

#### 解决的问题

- 家长和教师需要快速准备涂色、描红或临摹活动材料。
- 不同年龄儿童对图案大小、线条深浅和辅助格线的需求不同。
- 批量制作同主题绘画卡片耗时。

#### 适合人群

幼儿园和小学低年级儿童、家长、美术启蒙教师、托管班和亲子活动组织者。

### 4.7 趣味文字贴纸

#### 功能点

- 支持输入中文、拼音、英文或短句，按换行和多种标点自动拆分。
- 单次最多生成 72 个贴纸，内容过长时自动换行。
- 提供大、中、小三种尺寸，对应 2×4、3×5 和 4×6 的 A4 排版。
- 提供圆角、圆形、云朵和无底板四种外形。
- 提供圆润卡通、手写可爱和粗体醒目三种字体风格。
- 提供糖果、阳光、海洋和花园四套配色。
- 可调整白色描边粗细。
- 可选择显示裁剪线和小装饰。
- 内容过多时自动分页。

#### 解决的问题

- 家庭奖励贴、物品标签、识字卡和课堂装饰需要单独设计。
- 用户没有图形设计工具或不会进行整页拼版。
- 多个贴纸需要统一风格、尺寸和裁剪辅助线。

#### 适合人群

家长、幼儿园及小学教师、手账爱好者、亲子活动和班级活动组织者。

### 4.8 乐谱打印

#### 功能点

- 支持五线谱、大谱表、吉他谱、尤克里里谱和简谱。
- 支持空白练习纸和经典曲目两种模式。
- 内置《小星星》《欢乐颂》《两只老虎》《铃儿响叮当》等 19 首经典曲目。
- 空白谱纸可自定义主标题、副标题和作者信息。
- 可选择高音、低音、中音或无谱号。
- 可调整谱线间距和谱表上下间距。
- 提供炭灰、铅笔灰、护眼绿、纯净蓝和复古棕等线条颜色。
- 吉他相关练习可显示常用和弦图、空白和弦格或不显示和弦。
- 根据页面空间自动计算谱表数量与分页。

#### 解决的问题

- 乐器学习时临时缺少合适规格的空白谱纸。
- 不同乐器、谱号和书写习惯对谱线格式要求不同。
- 初学者需要从熟悉的经典旋律开始识谱和抄谱。

#### 适合人群

音乐初学者、钢琴与弦乐学习者、吉他和尤克里里学习者、音乐教师及家长。

### 4.9 留言与建议

#### 功能点

- 提供新模板需求提交入口。
- 提供排版、下载和题目错误等问题反馈入口。
- 使用评论区承载用户留言和产品建议。

#### 解决的问题

- 用户无法在现有模板中找到所需内容时，需要明确的需求反馈渠道。
- 产品问题需要集中收集，便于后续修复与迭代。

#### 适合人群

所有使用者。

## 6. 典型使用流程

1. 用户从首页选择数学、语文、拼音、英语、笔记、绘画、贴纸或乐谱。
2. 在生成设置中选择题型或模板。
3. 根据需要调整题量、内容、样式、颜色或辅助信息。
4. 在右侧或下方实时检查 A4 预览效果。
5. 数学和拼音练习可重新生成，直到内容符合需求。
6. 选择直接打印、下载 PDF 或下载图片。
7. 将打印材料用于课堂、家庭练习、兴趣活动或个人记录。

## 7. 当前产品边界

- 产品以生成和输出纸质材料为主，不包含在线答题、自动判分、错题统计或学习进度管理。
- 练习内容主要聚焦小学基础学习与通用纸张模板，不等同于完整课程体系。
- 打印效果会受到浏览器、打印机驱动、纸张和用户打印设置影响。
- 图片保存和系统分享能力依赖移动设备、HTTPS 环境及浏览器支持情况。
- 汉字笔顺数据加载失败时，会降级为普通示范与描红内容。
- 当前用户内容主要保留在页面使用过程中，产品不是云端文档管理或长期存储平台。

## 8. 产品一句话介绍

向日葵打印是一款让家长、教师和学生在浏览器中快速生成、定制并打印学习练习纸与实用模板的在线工具。

## 9. 首页新功能提醒配置

首页会轮播展示新上线功能的提醒卡片。每条提醒自上线日 00:00 起展示 7 天，第 7 天结束后自动从首页移除；当同时有多条有效提醒时，首页会自动轮播。用户点击提醒卡片会直接进入对应功能页面，同时在当前浏览器中隐藏该条提醒；刷新页面后仍会保持，新上线且未点击的提醒不受影响。

### 9.1 配置位置

- 公告列表和展示期限：`src/constants/featureAnnouncements.ts`
- 首页轮播渲染与跳转：`src/views/Home.vue`
- 中英文提醒文案：`src/i18n.ts` 的 `home.featureAnnouncements` 和 `home.featureNotice`

### 9.2 新增一条提醒

在 `featureAnnouncements` 数组中添加一项：

```ts
{
  id: 'featureId',
  publishedAt: 'YYYY-MM-DD',
  path: '/generator/feature-path',
}
```

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `id` | 功能的唯一标识，用于读取文案 | 与 `src/i18n.ts` 中的键一致 |
| `publishedAt` | 上线日期 | 使用 `YYYY-MM-DD`，从当日 00:00 开始计时 |
| `path` | 点击提醒后的站内路径 | 应指向已注册的路由 |

随后在 `src/i18n.ts` 的中文和英文 `home.featureAnnouncements` 中，分别补充同名 `id` 的 `title`、`description`、`action`：

```ts
featureId: {
  title: '新功能标题',
  description: '一句话说明功能的核心价值。',
  action: '立即使用',
}
```

### 9.3 当前示例

课程表模板的配置为：

```ts
{
  id: 'timetable',
  publishedAt: '2026-08-25',
  path: '/generator/timetable',
}
```

对应首页提醒标题为“课程表模板上线了”，操作文案为“立即使用”。该提醒会在 2026-09-01 00:00 后自动停止展示。
