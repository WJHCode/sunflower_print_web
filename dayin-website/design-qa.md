# 拼音拼读第一版视觉核对

## 参考目标

用户提供的“声母与单韵母拼读”练习纸截图：A4 纵向、两列分组卡片、每组五个声调、声母—韵母到完整拼写的练习路径。

## 核对范围

- 默认页面：`/generator/pinyin-reading`
- 默认状态：`b-a / b-o / b-i / b-u`，显示拼读结果
- 交互状态：切换到三个音节，确认 3 组声母、韵母和颜色配置出现
- 浏览器视口：1280 × 720；移动端使用项目已有缩放策略

## 结果

- 两列卡片、标题胶囊、五声调行、答案框和纸张预览均正常渲染。
- 声母和韵母拆分内容使用每个音节独立的颜色配置，完整拼写保持黑色。
- 颜色调整为红、黄、绿、黑、橙、蓝六种固定色；每个音节独立选色。
- 每个完整拼写后显示可编辑的汉字和组词。
- 默认 4 组内容在 A4 纸张范围内，三音节配置可正常切换。
- `npm run build` 通过。
